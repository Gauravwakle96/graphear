# Graphear

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + TypeScript + Vite, from the plan the user accepted. Node/Express and SQLite
provide the requested backend, private graph library and explicit read-only sharing.

## Users

Blind and low-vision students studying flowcharts and decision processes. Teachers
prepare/review diagrams and provide repair exercises. A sighted canvas complements
the complete keyboard and structured text interaction.

## Product Purpose

Import, verify, explore, edit, compare and learn from flowcharts independently.
Success means correct bounded graph reasoning and usable accessible workflows.

## Positioning

A source-reviewed diagram-to-learning workflow joins accessible editing, changes
in reachability, repair missions and feedback based on a checked graph. Existing
diagram readers/editors exist; no world's-first or guaranteed-prize claim is made.

## Operating Context

NovaStark software hackathon prototype, developed in the user's supplied repository.
PNG/JPEG/SVG/JSON inputs; local image processing, keyboard/screen reader use and
portable learning exports. Anonymous private workspace is an explicitly marked
implementation assumption while the optional account preference is pending.

## Capabilities and Constraints

Validated bounded flowcharts; review of inferred connections; accessible editing
and undo; deterministic path comparisons; repair missions; teach-back; local saves;
server saves and revocable read-only sharing; native optional speech.
No arbitrary uploaded execution, inferred clinical benefit, or general scientific
diagram understanding. Voice availability depends on browser/OS. Initial OCR is English.

## Brand Commitments

Graphear is the user's requested spelling and repository name. The accepted plan
describes a calm green-and-neutral working screen, readable type and light/dark themes.

## Evidence on Hand

No real user-study results, testimonials or measured learning improvement exist.
Authored diagrams and missions are synthetic examples, visibly labelled as such.

## Product Principles

Preserve uncertainty until review. Explain graph facts with source references.
Offer equivalent keyboard actions. Keep original documents local. Report actual tests.

## Accessibility & Inclusion

All essential actions available with keyboard and structured screen-reader content,
visible focus, semantic forms, contrast, reduced motion and optional speech.
