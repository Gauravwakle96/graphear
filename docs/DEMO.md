2. Open Practice → Start repair mission. Check the broken graph; it explains the missing connection. In Edit, connect Verify documents to Application approved with “Complete”. Check repair again.
3. Open Compare. Show the added connection and approval's restored reachability. Undo and redo the repair.
4. Import `apps/web/public/examples/scholarship.svg`. Review source, labels and proposed connections. Explain that extracted arrows are not trusted automatically. Correct and explicitly confirm.
5. Save on this device or in the private workspace. Create a read-only share link, open it, and revoke it. Export a portable learning pack.
